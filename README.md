# Landscape Genomics of Ruaha-Rufiji River Basin Cichlids (Astatotilapia spp.)
This repository contains data processing, bioinformatic workflows, and visualization scripts for investigating the landscape genomics, 
adaptive variation, and spatial demographic structure of Astatotilapia cichlids across the Ruaha-Rufiji River Basin (RRRB), Tanzania.

# Project Overview
Dataset: 70 whole genomes (24 newly resequenced, 46 archived/outgroups).
Workflow: Automated Snakemake pipeline executing read quality control, alignment, 
variant calling, and SNP annotation (SnpEff).
Analytical Framework: Genotype-Environment Associations via partial Redundancy Analysis (pRDA), haplotype sweep detection (iHS), 
and population diversity metrics (π, ROH, Tajima's D).
